# Codon Usage Pattern Analysis

This program analyzes a DNA sequence and calculates the frequency of each codon (triplet of nucleotides).

## Features

- Reads DNA sequence from a text file
- Splits DNA into codons
- Counts codon occurrences
- Calculates codon frequency
- Displays results in a formatted table

## Example Output

```
Total Codons: 16

Codon    Count      Frequency
------------------------------
ATG      3          0.1875
GCT      2          0.1250
GAA      1          0.0625
...
```

## Concepts Used

- Python Functions
- File Handling
- Loops
- Dictionaries
- Collections.Counter
- Basic Bioinformatics

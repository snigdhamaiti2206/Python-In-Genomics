# Multiple Sequence Alignment Analysis

The program:
- Reads DNA sequences
- Aligns them by padding shorter sequences
- Displays aligned sequences
- Calculates sequence identity

## Requirements

Python 3.x

## Example Output

```
Aligned Sequences

ATGCGTA-
ATGCGT--
ATGCCGTA
ATGCGGA-

Sequence Identity

Sequence 1: 100.00%
Sequence 2: 87.50%
Sequence 3: 87.50%
Sequence 4: 87.50%
```

- File handling
- Lists

# Phylogenetic Tree Construction using Python

## Overview

This project demonstrates how to construct a simple phylogenetic tree from aligned DNA sequences using Biopython.

## Features

- Read aligned DNA sequences from a FASTA file
- Calculate pairwise sequence distances
- Build a phylogenetic tree using the UPGMA algorithm
- Display the tree in ASCII format
- Export the tree in Newick format

## Output

- Distance matrix
- ASCII phylogenetic tree
- `phylogenetic_tree.nwk`

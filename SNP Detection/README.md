# SNP Detection Tool using Python

## Description

The program compares two DNA sequences of equal length and identifies nucleotide differences.

Example:

Reference:
ATGCGTACGTTAGC

Sample:
ATGAGTACATTAGT

Output:

Position 4 : C → A
Position 9 : G → A
Position 14 : C → T

## Features

- Compare two DNA sequences
- Detect SNP positions
- Report nucleotide changes
- Beginner-friendly code
- No external libraries required

## Requirements

Python 3.x
